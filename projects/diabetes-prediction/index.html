Diabetes Prediction

A modernized version of my earlier academic Decision Tree project, rebuilt with clearer data preparation, exploratory analysis, reproducible evaluation and a maintainable Python workflow.

PythonRscikit-learnDecision TreeEDA
View source ↗Project README

Problem

Classify diabetes status from eight clinical measurements in the benchmark Pima Indians Diabetes dataset.

Original work

The academic project used R and a Decision Tree with 500 training records and 268 test records.

Modernized workflow

Stratified holdout, median imputation inside a pipeline, Decision Tree primary model, Logistic Regression benchmark and 5-fold ROC-AUC cross-validation.

Reported result

79.48% accuracy was reported in the original academic project. New results are generated by the current code rather than copied forward.

Important: This is a machine-learning portfolio project and not a medical diagnostic system. Model performance on this small benchmark should not be interpreted as clinical performance.
