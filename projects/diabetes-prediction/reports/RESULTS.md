# Results and reproducibility notes

## Original academic result

The original project report used R's `tree` package, trained on records 1–500 and tested on records 501–768. The report recorded a test accuracy of **0.7947761 (79.48%)** for the Decision Tree.

## Refactored implementation

The current portfolio version intentionally does not copy that result into the new experiment. It uses a stratified 80/20 split, median imputation inside a scikit-learn pipeline, a constrained Decision Tree, and 5-fold stratified cross-validation.

Run:

```bash
python download_data.py
python src/eda.py
python src/train.py
```

The training script writes the fresh model comparison to `reports/model_results.csv` and the confusion matrix to `reports/figures/confusion_matrix.png`.

This separation keeps the historical academic result distinguishable from results generated by the modernized implementation.
